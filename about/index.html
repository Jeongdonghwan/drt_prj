도로시펫 부산본점

도로시펫은 강아지·고양이 분양 매장입니다. 부산본점은 부산광역시 사상구 가야대로 336 A동 (주례동)에 있고, 아이들 휴식 때문에 방문은 예약제로 받습니다. 예약 시간에 전문 펫플래너가 1:1로 상담하고, 건강 확인은 예비 보호자가 동물병원에서 직접 합니다.

01

분양은 이렇게 진행됩니다

  1. SNS·전화로 방문 예약

    전화, 오픈카톡, 인스타그램 DM으로 방문 날짜를 잡습니다.

  2. 1:1 맞춤 상담

    매장에서 전문 펫플래너가 아이의 성격·특징·생활 습관을 설명하고 집 환경에 맞는 아이를 함께 고릅니다.

  3. 동물병원 건강 확인

    예비 견주·묘주님이 동물병원에 직접 가서 기본 건강검진으로 상태를 확인합니다.

  4. 계약서 작성·주의사항

    소비자보호 기준에 맞춘 계약서를 쓰고 사료 급여, 적응·합사 기간 같은 주의사항을 안내합니다.

  5. 분양 후 사후관리

    분양 뒤에도 궁금한 점은 전화·SNS로 상담합니다. 추가 비용은 없습니다.

02

도로시펫이 지키는 것

  • 건강 상태 확인

    입양 전 예비 견주·묘주님이 직접 기본검사로 건강 상태를 확인한 뒤 분양합니다.

  • 합법적인 분양 절차

    정부 규정을 지키는 분양 절차로 계약합니다.

  • 1:1 맞춤 상담

    매장 방문 예약 후 전문 상담사가 1:1로 상담합니다.

  • 분양 후 사후관리

    분양 뒤 사후관리·후케어를 추가 비용 없이 돕습니다.

  • 확실한 출신

    전문 켄넬과 캐터리에서 태어난 출처가 명확한 아이들입니다.

  • 동물등록 대행

    사상구에서 지정한 동물등록 대행업체입니다(동물보호법 제12조 제4항).

03

홈딜리버리

매장 상담으로 분양을 정한 뒤, 직접 오기 어려우면 집까지 데려다줍니다.

  1. 매장 방문 후 상담·분양 결정
  2. 출발 전 아이 상태 확인 사진 촬영·첨부
  3. 배송 날짜 지정
  4. 분양 관련 서류 지참해 출발
  5. 집 앞 도착
  6. 계약서 작성·주의사항 설명 후 완료
