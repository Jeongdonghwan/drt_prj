04

도로시펫 분양 5단계

창원시에서 강아지를 알아보신다면 먼저 방문 날짜를 잡아 주세요. 상담 순서는 아래와 같습니다.

  1. SNS·전화로 방문 예약

    전화, 오픈카톡, 인스타그램 DM으로 방문 날짜를 잡습니다.

  2. 1:1 맞춤 상담

    매장에서 강아지의 성격과 생활 습관을 직접 보고, 집 환경에 맞는지 펫플래너와 함께 판단합니다.

  3. 동물병원 건강 확인

    예비 견주·묘주님이 동물병원에 직접 가서 기본 건강검진으로 상태를 확인합니다.

  4. 계약서 작성·주의사항

    소비자보호 기준에 맞춘 계약서를 쓰고 사료 급여, 적응·합사 기간 같은 주의사항을 안내합니다.

  5. 분양 후 사후관리

    분양 뒤에도 궁금한 점은 전화·SNS로 상담합니다. 추가 비용은 없습니다.

방문 전 예약하면 1:1로 상담합니다.

05

창원시와 도로시펫

창원시 보호자님이 많이 묻는 것은 건강 확인과 사후관리입니다. 건강은 동물병원에서 직접 확인하고, 분양 뒤 상담은 추가 비용이 없습니다.

창원시에서 강아지 분양을 알아보신다면 방문 전 전화나 카톡으로 날짜를 먼저 잡아 주세요. 예약 시간에 1:1로 상담합니다.

창원시에서 부산 사상구까지 오기 어려우면, 매장 상담으로 분양을 정한 뒤 홈딜리버리로 집까지 데려다줍니다.

홈딜리버리 순서

  1. 매장 방문 후 상담·분양 결정
  2. 출발 전 아이 상태 확인 사진 촬영·첨부
  3. 배송 날짜 지정
  4. 분양 관련 서류 지참해 출발
  5. 집 앞 도착
  6. 계약서 작성·주의사항 설명 후 완료
06

도로시펫이 지키는 것

  • 1:1 맞춤 상담

    매장 방문 예약 후 전문 상담사가 1:1로 상담합니다.

  • 확실한 출신

    전문 켄넬과 캐터리에서 태어난 출처가 명확한 아이들입니다.

  • 건강 상태 확인

    입양 전 예비 견주·묘주님이 직접 기본검사로 건강 상태를 확인한 뒤 분양합니다.

07

강아지 키우기, 많이 묻는 세 가지

강아지 건강검진은 어디서 하나요?
분양 전 예비 견주님이 동물병원에서 기본검사로 직접 확인합니다. 이후 접종 일정은 다니실 동물병원과 정합니다.
강아지 털 빠짐은 어느 정도인가요?
빠짐은 적어도 엉킴 관리를 위해 빗질은 꾸준히 합니다.
강아지 사료는 언제 바꾸나요?
첫 주는 먹던 사료를 그대로 주고, 바꿀 때는 며칠에 걸쳐 섞어 가며 바꿉니다.
08

자주 묻는 질문

창원시까지 데려다주나요?

매장 상담으로 분양을 정한 뒤 홈딜리버리를 신청하면, 출발 전 상태 사진을 보내고 지정한 날짜에 집 앞에서 계약서와 주의사항을 안내합니다.

강아지 분양가는 얼마인가요?

혈통·모색·성별·월령에 따라 달라 아이를 보고 상담으로 안내합니다. 전화 010-2236-8276.

방문은 예약해야 하나요?

네. 전화, 오픈카톡, 인스타그램 DM으로 예약하면 예약 시간에 1:1로 상담합니다.

건강은 어떻게 확인하나요?

예비 견주·묘주님이 동물병원에 직접 가서 기본 건강검진으로 확인한 뒤 분양합니다.
